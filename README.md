# 中心机柜动力环监一体化系统

面向数据中心一体化微模块的动力与环境监控平台。系统以 2 s 周期采集机柜 PDU、列头柜、UPS、精密空调与温湿度测点，围绕“电参采集 → 环境联测 → 温升识别 → 异常联判 → 结果反馈”构建完整的监测、分析与优化闭环。

## 功能模块

| 模块 | 子模块 | 说明 |
| --- | --- | --- |
| 运行总览 | — | 关键指标、微模块平面态势（进/出风温度、负载率、湿度）、一体化运行架构、能效与供配电、精密空调、最新告警 |
| 电参采集 | 信号采集 | 40 路 PDU 通道实时值、越限与通讯状态、采集网关巡检、列头柜三相进线 |
|  | 波形分析 | 瞬时电压/电流波形、FFT 谐波频谱、三相相量图、电能质量评估（GB/T 12325、14549 等） |
|  | 序列生成 | 按对象/参数/时间窗/粒度/聚合方式重采样生成时间序列，支持统计特征与 CSV / JSON 导出 |
| 环境联测 | 湿度监测 | 相对湿度、露点、凝露裕度分布，ASHRAE 推荐区焓湿工况图，合规评估 |
|  | 关联分析 | Pearson 相关矩阵、散点回归、时滞互相关与关联发现 |
|  | 路径识别 | 主送风路径与热回流、冷旁通、供冷不足等异常气流路径识别与拓扑可视化 |
| 温升识别 | 节点定位 | 120 个温度节点综合评分，空间/时间偏离分析，竖向插值定位热点 U 位 |
|  | 热向分析 | 楼面热向图、列内横向温差扩散、基于因果滞后互相关的热传播路径、垂直热分层 |
|  | 温升筛选 | 滑动窗口回归温升速率，多条件（阈值、侧别、温度下限）筛选与持续时长统计 |
| 异常联判 | 节点排序分析 | 电参偏离、温升异常、环境越限、分布偏移四类证据加权评分与联合加权排序 |
|  | 分布一致性计算 | 近期窗口与基线窗口的 JS / KL 散度、KS 检验、PSI，一致性矩阵与箱线图 |
|  | 融合路径构建 | 多源证据按因果时序关联为“证据 → 成因”推理路径，给出置信度与处置建议 |
| 结果反馈 | 路径链组提取 | 对融合路径做时序追踪、片段合并与成因聚类，提炼共性传导模式 |
|  | 负载响应分析 | 负载阶跃检测与 FOPDT 热响应辨识（增益 K、时间常数 τ、纯滞后 θ） |
|  | 能效路径筛选 | 制冷/气流/负载/供电优化路径推演、约束校验、Pareto 筛选、策略下发与效果跟踪 |
| 告警中心 | — | 分级告警、过滤检索、批量确认、告警时序追溯 |

## 技术栈

- React 18 + TypeScript + Vite 6
- Ant Design 5（深色 / 浅色主题切换）
- ECharts 5（按需引入）
- 纯前端运行，HashRouter 路由，可直接部署到任意静态服务器

## 本地运行

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览生产构建
```

## 目录结构

```
src/
├── core/                 # 数据与分析内核
│   ├── topology.ts       # 机房拓扑：机柜、空调、列头柜、UPS、温度节点
│   ├── model.ts          # 动力与环境过程模型：负载—电参—热—湿耦合
│   ├── engine.ts         # 采集引擎：周期采集、时序库写入、告警判定、订阅通知
│   ├── history.ts        # 环形时序库（最近 60 分钟全量测点）
│   ├── alarms.ts         # 告警规则（越限 + 回差 + 持续确认）与生命周期管理
│   ├── analytics.ts      # 通用统计：相关、回归、互相关、直方图、散度、KS、DFT
│   ├── airflow.ts        # 气流路径识别
│   ├── thermal.ts        # 热点定位、热传播方向、温升筛选
│   ├── anomaly.ts        # 节点评分、分布一致性、融合路径
│   ├── feedback.ts       # 路径链组、负载响应辨识、能效路径
│   └── cache.ts          # 分析结果节流缓存
├── components/           # 图表封装、机房平面、机柜立面、机柜详情抽屉等
├── layouts/              # 框架布局（侧边导航、顶栏）
├── pages/                # 各功能页面
└── theme/                # 主题令牌与色带
```

## 数据接入

采集引擎 `src/core/engine.ts` 每个周期调用 `computeSnapshot(t)` 生成全量采样（`Snapshot`），写入时序库并驱动告警判定。对接现场采集网关（Modbus-TCP / SNMP / BACnet 等）时，将该函数替换为网关数据的解析与映射，保持 `Snapshot` 结构不变，上层分析与页面无需改动。
